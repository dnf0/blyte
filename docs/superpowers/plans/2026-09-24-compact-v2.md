# Compact v2 Implementation Plan: mask only at folds

> **For agentic workers:** Execution is delegated to headless `agy`, one task per dispatch; Claude reviews each task before the next is sent. Steps use checkbox (`- [ ]`) syntax for tracking. Do NOT `git push`, open PRs, publish crates, or call any model API; commit locally only.

**Goal:** `compact` masks superseded outputs **only when a fold happens**. A fold already rewrites the prompt from its new digest onward, so the masking costs no extra cache miss.

**Why (superstate-eval FINDINGS §13.39):** `compact` v1 applied supersession masks per completed 40-message epoch. It cut the average prompt by 25% and cached reads by 21%, but raised **fresh** input by 34%: each epoch's masks re-prefilled the tail at the fresh price, ten times the cached price. Net cost didn't fall ($1.26 against `folded`'s $1.18).

**Design:**
- `Folded` gains a pure `plan(rest)` returning its folds, the verbatim tail's start and **the index at which the most recent fold was triggered**. `build` is unchanged in behaviour and uses the plan.
- `Compact` judges supersession only by calls up to the last fold's trigger. Before the first fold, nothing is masked. Between folds the cutoff is fixed, so the prompt is pure append. It changes only when a new fold changes it anyway.
- The `epoch_messages` field is removed. De-duplication is unchanged: it is decided when a duplicate arrives, and only references outputs still visible.

**Tech Stack:** Rust 2021.

//! `compact`: `folded` plus exact reductions of tool output. Superseded outputs are masked only
//! when a fold happens (the prompt is rewritten then anyway), duplicates of visible outputs are
//! referenced, and calls are never lost.

use serde_json::{json, Value};
use superstate_agent::context::{Compact, ContextStrategy, Conversational};
use superstate_agent::state::State;
use superstate_provider::Message;

fn call(n: usize, name: &str, args: Value) -> Message {
    Message::ToolCall {
        id: format!("c{n}"),
        name: name.into(),
        arguments: args,
        signature: None,
    }
}

fn res(n: usize, name: &str, content: &str) -> Message {
    Message::ToolResult {
        id: format!("c{n}"),
        name: name.into(),
        content: content.into(),
        is_error: false,
    }
}

fn open() -> Message {
    Message::User("Begin. fix it".into())
}

fn compact(budget: usize) -> Compact {
    Compact {
        budget_tokens: budget,
        min_dedup_chars: 200,
    }
}

fn st() -> State {
    State::new("fix it", "")
}

fn digests(out: &[Message]) -> usize {
    out.iter()
        .filter(|m| matches!(m, Message::User(t) if t.starts_with("## Earlier turns, folded")))
        .count()
}

fn result_text<'a>(out: &'a [Message], needle: &str) -> Option<&'a str> {
    out.iter().find_map(|m| match m {
        Message::ToolResult { content, .. } if content.contains(needle) => Some(content.as_str()),
        _ => None,
    })
}

/// Twenty filler turns (~100 tokens each), then `tail`, then one large output that triggers a
/// fold, whose older half is filler, so `tail` stays verbatim.
fn with_fold(tail: Vec<Message>) -> Vec<Message> {
    let mut h = vec![open()];
    for t in 0..20 {
        h.push(call(100 + t, "bash", json!({"command": format!("echo filler {t}")})));
        h.push(res(100 + t, "bash", &format!("filler {t} {}", "f".repeat(400))));
    }
    h.extend(tail);
    h.push(call(900, "bash", json!({"command": "cat big.log"})));
    h.push(res(900, "bash", &"g".repeat(2_000)));
    h
}

#[test]
fn the_prompt_only_changes_when_a_fold_happens() {
    let c = Compact {
        budget_tokens: 1_500,
        min_dedup_chars: 20,
    };
    let mut h = vec![open()];
    for t in 0..60 {
        let (name, args) = match t % 3 {
            0 => ("read", json!({"path": format!("f{}.rs", t % 4)})),
            1 => ("edit", json!({"path": format!("f{}.rs", t % 4), "old": "a", "new": "b"})),
            _ => ("bash", json!({"command": "pytest -q"})),
        };
        h.push(call(t, name, args));
        h.push(res(t, name, &format!("output of {name} {}", "z".repeat(150 + t % 2))));
    }
    let mut folds_seen = 0;
    for n in 2..h.len() {
        let a = c.build(&st(), &h[..n]);
        let b = c.build(&st(), &h[..n + 1]);
        if b.len() >= a.len() && b[..a.len()] == a[..] {
            continue;
        }
        assert_ne!(
            digests(&a),
            digests(&b),
            "the prompt changed without a fold at n={n}"
        );
        folds_seen += 1;
    }
    assert!(folds_seen > 0, "expected folds in this history");
}

/// Where `Folded` put its boundaries over `history[1..]`: each fold `(a, b)`, the start of the
/// verbatim tail, and the index at which the most recent fold was triggered (if any).
struct FoldPlan {
    folds: Vec<(usize, usize)>,
    seg_start: usize,
    last_trigger: Option<usize>,
}

impl Folded {
    /// Greedy boundaries from the start: each fold depends only on messages before it, so the next
    /// turn reproduces every earlier fold exactly.
    fn plan(&self, rest: &[Message]) -> FoldPlan {
        let mut folds: Vec<(usize, usize)> = Vec::new();
        let mut seg_start = 0;
        let mut size = 0;
        let mut last_trigger = None;
        for i in 0..rest.len() {
            size += approx_tokens(&rest[i]);
            if size <= self.budget_tokens {
                continue;
            }
            // Fold roughly the older half, cutting only between turn blocks (never after a call
            // or before a result), so a call is never separated from its result or from calls in
            // the same batch. No safe cut yet: keep accumulating.
            let target = seg_start + (i + 1 - seg_start) / 2;
            let lo = target.max(seg_start + 1);
            let Some(cut) = (lo..=i).find(|&j| {
                !matches!(rest[j], Message::ToolResult { .. })
                    && !matches!(rest[j - 1], Message::ToolCall { .. })
            }) else {
                continue;
            };
            folds.push((seg_start, cut));
            size = rest[cut..=i].iter().map(approx_tokens).sum();
            seg_start = cut;
            last_trigger = Some(i);
        }
        FoldPlan {
            folds,
            seg_start,
            last_trigger,
        }
    }
}

# A Spending Cap — Implementation Plan

> **For agentic workers:** Implement exactly one task. Do NOT `git push`, open PRs, publish crates, or call any model API; commit locally only. This plan is shadow-run: agy and blyte each implement it independently.

**Goal:** `blyte --max-cost <usd>` stops a run before a model call that would begin once the run's
list-price spend has reached the cap, with outcome `budget_exhausted` and a report that says why.
The cap is refused up front for a model whose price blyte does not know, rather than silently not
enforced.

**Why:** a cost cap was removed in #66 because on Gemini 3.8 Flash runs it never bound (a typical run
costs $0.15–4). blyte is gaining pricier providers (Anthropic, OpenAI-compatible, Kimi K3 via
Bedrock), where an hour-long runaway run (the `--max-seconds` bound) costs real money; the time bound
alone does not bound spend.

**Tech Stack:** Rust 2021.

## Global Constraints

- Work only in your own worktree (already on its own branch).
- Existing tests must pass. `TaskConfig` is built field by field in a few `crates/blyte-cli/tests/`
  files; the only change allowed to them is adding the new field (`max_cost_usd: None`) to those
  literals so they compile.
- Do NOT add fields to `Budget` or `Runner` (they are built field by field in many tests). The cap
  lives on `State` (see below), which tests build with `State::new`.
- The report change is additive (`SCHEMA_VERSION` stays 1).
- Commit with `--no-gpg-sign` and the exact message below.

### Task 1: The cap

**What to build** (names are part of the contract):

- `crates/blyte-agent/src/state.rs`: the orchestrator part of `State` gains
  `pub max_cost_usd: Option<f64>` (`None` from `State::new`; serde default so old state still loads).
- `crates/blyte-agent/src/run.rs`: before each model call, if `state.orchestrator.max_cost_usd` is
  `Some(cap)` and `blyte_provider::pricing(&self.provider.model_id())` is `Some(price)` and
  `price.cost(&report.usage) >= cap`, stop with `Outcome::BudgetExhausted` and set
  `report.cost_capped = true` (a new `pub cost_capped: bool` on `RunReport`, default false).
- `crates/blyte-cli`: `--max-cost <USD>` (`max_cost_usd: Option<f64>` on `Cli` and `TaskConfig`),
  copied onto the state before the run. If it is set and `pricing(model_id)` is `None`, exit with an
  error before any model call: `--max-cost needs a known price for <model>; none is known`. The run
  report gains `max_cost_usd: Option<f64>` and `cost_capped: bool`.

//! A spending cap stops the run before the next model call once list-price spend reaches it.

use std::sync::Mutex;

use blyte_agent::context::Conversational;
use blyte_agent::fs::LocalFs;
use blyte_agent::run::{Budget, Outcome, Runner};
use blyte_agent::shell::LocalShell;
use blyte_agent::state::State;
use blyte_provider::{Provider, ProviderError, Request, Response, ToolCall, Usage};
use serde_json::json;

/// Always asks for one more tool call; each call reports 100K fresh input and 10K output tokens,
/// which at Gemini 3.8 Flash list price is $0.075 + $0.0375 = $0.1125 per call.
struct Spender {
    calls: Mutex<u32>,
}

impl Provider for Spender {
    fn complete(&self, _req: &Request) -> Result<Response, ProviderError> {
        let mut n = self.calls.lock().unwrap();
        *n += 1;
        Ok(Response {
            tool_calls: vec![ToolCall {
                id: format!("c{n}"),
                name: "bash".into(),
                arguments: json!({"command": "true"}),
                signature: None,
            }],
            usage: Usage { input: 100_000, cached: 0, output: 10_000, thinking: 0 },
            ..Default::default()
        })
    }
    fn model_id(&self) -> String {
        "gemini/gemini-3.8-flash".into()
    }
}

fn run(cap: Option<f64>) -> (Outcome, blyte_agent::run::RunReport, u32) {
    let d = tempfile::tempdir().unwrap();
    let p = Spender { calls: Mutex::new(0) };
    let r = Runner {
        provider: &p,
        shell: &LocalShell,
        fs: &LocalFs,
        context: &Conversational,
        root: d.path().to_path_buf(),
        budget: Budget { max_turns: 20, max_gate_attempts: 1, max_duration: None },
        rollback: false,
        on_event: None,
    };
    let mut st = State::new("g", "true");
    st.orchestrator.max_cost_usd = cap;
    let (outcome, report) = r.run(&mut st);
    let calls = *p.calls.lock().unwrap();
    (outcome, report, calls)
}

#[test]
fn the_run_stops_once_spend_reaches_the_cap() {
    let (outcome, report, calls) = run(Some(0.30));
    assert_eq!(outcome, Outcome::BudgetExhausted);
    assert!(report.cost_capped);
    // $0.1125 per call: after 3 calls spend is $0.3375 >= $0.30, so a 4th call never starts.
    assert_eq!(calls, 3, "stopped before the call that would begin over the cap");
}

#[test]
fn without_a_cap_the_turn_budget_is_what_stops_it() {
    let (outcome, report, calls) = run(None);
    assert_eq!(outcome, Outcome::BudgetExhausted);
    assert!(!report.cost_capped);
    assert_eq!(calls, 20);
}
```

//! `--max-cost` is refused for a model with no known price, before any model call.

use std::process::Command;

#[test]
fn a_cap_on_an_unpriced_model_is_refused() {
    let d = tempfile::tempdir().unwrap();
    let out = Command::new(env!("CARGO_BIN_EXE_blyte"))
        .args(["--max-cost", "1.0", "--model", "ollama/qwen3:14b", "--max-turns", "1", "do nothing"])
        .current_dir(d.path())
        .env("OLLAMA_HOST", "http://127.0.0.1:9")
        .env_remove("GEMINI_API_KEY")
        .output()
        .unwrap();
    assert!(!out.status.success());
    let err = String::from_utf8_lossy(&out.stderr) + String::from_utf8_lossy(&out.stdout);
    assert!(err.contains("--max-cost needs a known price"), "{err}");
}
```
